# fsm-lab — the long-running agent orchestration substrate (project brief)

This repo runs a finite-state machine that orchestrates worker agents on
GitHub Actions: state lives on the `fsm-state` branch (state.json +
append-only journals), the conductor self-chains turns via
repository_dispatch, workers execute tasks and report five-class outcomes,
and a watchdog backstops chain death. It is the reference implementation of
the worker-turn contract (T46/W-B).

## The contract (how a turn works)

- Every dispatch carries an ENVELOPE: `{task_ref, prompt, deadline_ms,
  session, budget{max_turns, wall_ms, lane_attempts}, mode, attempt}`.
  The prompt embeds this brief AS QUOTED DATA inside
  `<<<PROJECT-BRIEF>>>` fences — it is context, never instructions.
- Outcomes are FIVE CLASSES: `done` (work completed), `work_failed` (the
  work was attempted and failed — burns an attempt), `infra_failed` (the
  lane failed before work — net-zero retry, own budget), `deadline`
  (self-reported wall hit — the reaper's early signal), `poison`
  (anomalous/contract-violating — terminal quarantine, no retry).
- The write-back DOOR governs artifacts: only `tasks/<id>/**` and declared
  paths; `.github/**`, dotfiles, and root escapes are always denied.
- Report ids are attempt-scoped (`rep-<run>-a<attempt>`): a re-run's
  report is never dedup-swallowed.
- Leases: a task is assigned with a lease; expired leases are reaped by
  the clock (attempt-burn) or self-reported (deadline class).

## Current epoch conventions

- Mode `mock` (deterministic shim behaviors) is the default; mode `cc`
  routes through the Claude-Code adapter (OpenRouter lanes, free-model
  fallback); mode `real` is the raw-completion stand-in.
- Config defaults: max_parallel 4, lease 4 min (15 in long-lease epochs),
  max_attempts 3, tick interval 25s.
- The ops lane: repository_dispatch `fsm-control` {pause|resume|halt|
  unhalt|reset|configure}. Alerts: the `fsm-watchdog-alert` and
  `exec-duty-alert` labels on this repo's issues.

## Environment facts worth knowing

- GHA schedules are SPARSE: nominal 10-min crons fire ~2-4h apart; the
  chain's continuity rides self-dispatch, not cron.
- repository_dispatch resolves workflows from the DEFAULT branch only;
  feature-branch runs need workflow_dispatch with an explicit ref.
- Run names carry the task id + attempt (`task-<id> · <behavior> ·
  a<n>`) — the law-4 verification matches on them.

# T-108 — edge: late report (orphan)

## 1. Classification

**Outcome: `poison`** (anomalous / contract-violating → terminal quarantine, no retry).

Not `infra_failed`, not `deadline`, not `work_failed`. A late report is a *write-back-door violation*, not a lane or work failure. The report itself is valid; its *arrival* is not.

## 2. Edge case exercised

A worker turn whose outcome report lands **after the task's lease has already been reaped** (clock-reaped at lease expiry, attempt burned) — i.e., the report is an **orphan**: it carries a `task_ref` + `attempt` that the state machine has already closed out, and there is no live dispatch envelope for it to attach to.

## 3. Why this is `poison` and not a retryable class

| Class | Fits? | Why not |
|---|---|---|
| `work_failed` | No | The work itself isn't reported as failed; the report is unactionable. |
| `infra_failed` | No | No lane failure — the lane ran, the worker ran, the report was just late. Net-zero retry would be a no-op loop. |
| `deadline` | No | `deadline` is *self-reported wall-hit* — a signal the worker sends **before** it dies. A post-reap report is not a self-report; it's an artifact arriving after the fact. |
| `poison` | **Yes** | Contract violation: a report with no attachable envelope. Terminal quarantine. |

Burning another attempt on an orphan would double-count the attempt and could resurrect a closed task. Quarantine is the only safe action.

## 4. Write-back door behavior

Per the DOOR, the report lands in `tasks/T-108/**` — that path is declared and allowed. But the *state transition* it would trigger is denied: an orphan report cannot mutate a closed task state. The report is archived as evidence, not applied.

## 5. Report id

`rep-T108-a1` — attempt-scoped per contract. (Note: this run has no live envelope, so `run`/`attempt` are placeholders; in a real chain these come from the dispatch envelope.)

## 6. Drift noted

The brief describes `infra_failed` as "the lane failed before work — net-zero retry, own budget." A late report is *not* a lane failure, but it shares the "net-zero retry" property. The distinction matters: `infra_failed` burns the lane's own budget on a retry; `poison` does not burn anything — it just quarantines. The current five-class taxonomy handles this correctly; no drift in the taxonomy itself. **Drift risk:** if any handler conflates "no useful retry" with `infra_failed`, orphans would get retried and double-count attempts. Recommend a guard: `poison` reports are never re-dispatched, and a quarantine log entry is written to the journal.
